# Global Video Game Sales Analytics Dashboard

## Overview
This project presents an interactive Tableau dashboard analyzing global video game sales across genres, platforms, publishers, and years.

## Tools Used
- Tableau
- Excel
- Data Visualization

## Key Insights
- Action genre generated the highest sales.
- Nintendo was the leading publisher by total sales.
- PS2 was the top-performing gaming platform.
- Global sales peaked during the late 2000s.

## Dashboard Features
- Genre-wise sales analysis
- Yearly sales trends
- Top publishers by sales
- Top platforms by sales
- Interactive filters and KPIs

## Dataset
Video Game Sales Dataset containing 11,493 games, 31 platforms, and 579 publishers.
